# About Me

Hi, I’m Shubham Joshi — a Cloud & AI Engineer with a background in backend systems, cloud-native application development, distributed systems, machine learning, and AWS infrastructure engineering.

I completed my Master’s in Computer Science at Syracuse University, where I focused on cloud computing, artificial intelligence, machine learning, graph systems, operating systems, and sequential data analytics. My work primarily revolves around building production-style systems that combine software engineering with scalable cloud architecture and applied AI.

Over the past few years, I’ve built projects involving:

* serverless GenAI and RAG systems using Amazon Bedrock
* distributed cloud-native microservice architectures on AWS
* graph-based recommendation systems using Neo4j and Node2Vec
* time-series forecasting pipelines using SARIMAX and Gradient Boosting
* real-time computer vision applications
* CI/CD and infrastructure-as-code deployment pipelines using Terraform and GitHub Actions

I enjoy designing systems end-to-end — from backend architecture and cloud infrastructure to frontend integration and deployment workflows. I’m particularly interested in cloud engineering, AI infrastructure, retrieval systems, scalable backend systems, and production deployment architecture.

I’m currently focused on building cloud-native AI systems, improving my software engineering depth, and continuing to develop production-grade projects that combine cloud infrastructure, backend engineering, and applied machine learning.
